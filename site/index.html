Calculator for Linux

A tiny, instant calculator.

Alias Calc opens its window in 3 ms, idles in one thread, waking only for the compositor's ping, and does exact decimal math. It takes its colours from your desktop theme and works with the keyboard and a screen reader.

Features

Everything a calculator needs, and nothing it doesn't.

Exact decimals

Numbers are decimals, not floats, so 0.1 + 0.2 is 0.3 and 16-digit integers show exactly. Past a decimal's range it falls back to floating point, so 10 ^ 308 still works.

0.1 + 0.2 = 0.3

Keyboard first

Every key has a key: 0–9 . + - * (or x) / ^ %, Enter or =, Backspace (it repeats), C or Escape, and S to change sign. The numpad works with NumLock on or off.

Tab, arrows, Space

Copy and paste

Ctrl+C copies the result without separators. Paste a number with or without them: 1,234.5, 1 234,5 and 12,34 all work, and anything else is ignored.

Ctrl+C · Ctrl+V

Follows your theme

On aliasOS or Omarchy, the colours come from your live theme and change the moment it does. Any theme still meets WCAG AA: a colour that would be hard to read is adjusted.

Built-in dark palette otherwise

Screen reader

With a screen reader running when it opens, every key is a named button and the result is read out when it changes. The support loads only then, so it costs nothing otherwise; start the screen reader first.

Loads only when needed

No toolkit

Drawn on the CPU straight into a Wayland buffer, sharp at fractional scales. Besides the C runtime, it links only libxkbcommon.

1.05 MB, one thread

Themes

Your theme, readable.

Four themes, each window at its smallest size. Alias Calc reads three colours from the theme and works out the rest, nudging any text that would fall under 4.5:1.

Install

Build it, or take the package.

From source

$ git clone https://github.com/aliasproject/alias-calc
$ cd alias-calc
$ ./install.sh            # build, install into ~/.local

It installs the binary, the screen reader library, a desktop entry ("Calculator" in your launcher) and the icons. To remove them, run ./install.sh uninstall in the same folder.

Requirements

  • Linux on x86_64 or aarch64
  • A Wayland desktop
  • libxkbcommon
  • To build from source: a current stable Rust and a C linker

Packages

On aliasOS, it's in the aliasOS package repository:

$ sudo pacman -S alias-calc

Packages for other distributions aren't published yet. Until then, build from source.
